1. Общие сведения о проекте
Настоящий документ содержит техническое описание аркадной веб-игры «Cave Flight»,
разработанной на платформе ASP.NET Core с использованием технологии HTML5 Canvas для
клиентского рендеринга. Проект реализует двухмерный игровой процесс с непрерывным
перемещением персонажа (летучей мыши) сквозь динамически генерируемые подземные
локации (биомы), усложняющиеся по мере набора очков.

2. Архитектура и стек технологий

изображений в память браузера для исключения задержек (задержек кадров).

3. Ключевые системы и подсистемы
3.1. Генерация препятствий
Препятствия формируются в виде пар массивных скальных образований (верхних сталактитов и
нижних сталагмитов). Высота прохода рассчитывается со случайным смещением от центральной
оси экрана, обеспечивая равную и сбалансированную сложность. Верхние скалы
позиционируются строго от верхней границы (Y = 0), а нижние — от нижней границы экрана.

3.2. Система спрайтов и анимации персонажа
Персонаж имеет два динамических состояния: взлёт при импульсе вверх (спрайт bat_up) и
планирование при падении под действием гравитации (спрайт bat_down). Габариты персонажа
фиксированы (72×56 px) для точного расчета геометрических коллизий.

3.3. Параллакс-скроллинг и смена биомов
Фоновое изображение смещается с фиксированной скоростью, создавая эффект бесшовного
движения. Смена визуального биома (из 10 доступных пресетов) происходит автоматически через
каждые 20 набранных очков.

3.4. Оптимизация производительности
Все медиа-ресурсы предзагружаются до запуска игрового цикла. Рендеринг осуществляется без
попиксельной динамической обработки во время игры, что предотвращает падение частоты
кадров и гарантирует стабильную работу на слабых устройствах.

5. Руководство по развертыванию и запуску
  1. Предварительно установите .NET SDK 6.0 или более поздней версии.
  2. Выполните клонирование репозитория: git clone &lt;URL_РЕПОЗИТОРИЯ&gt;
  3. Перейдите в корневой каталог проекта: cd FlappyCave
  4. Выполните сборку и запуск приложения: dotnet run
  5. Откройте веб-браузер и перейдите по адресу локального узла (http://localhost:5000 или https://localhost:7136).
